Method

Every number is min/median/max over 10 runs after 1 discarded warm-up run, except a cold-cache pass, which cannot be repeated and stay cold. "4x CPU" is Chrome DevTools Protocol Emulation.setCPUThrottlingRate({ rate: 4 }). "Fast 3G" is Network.emulateNetworkConditions at 1.6 Mbps down, 150ms latency. Render time is measured inside the page with performance.now(), not around the Node round trip, so Playwright IPC overhead is excluded. Source: packages/cli/scripts/bench.mjs, packages/cli/scripts/bench-page.mjs.
